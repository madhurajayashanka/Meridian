# Meridian

Autonomous multi-agent research platform. Submit a query, get a fully cited research report.

**Stack:** Next.js · Spring Boot (GraphQL) · FastAPI (LangGraph) · PostgreSQL + pgvector · Redis · AWS Bedrock / OpenAI

---

## Architecture

```
Browser (Next.js)
    │ GraphQL + SSE
    ▼
Spring Boot API  ──REST──▶  FastAPI AI Service
    │                            │
    ▼                            ▼
PostgreSQL + pgvector        Redis Streams
(users, jobs, reports,       (job checkpoints,
 embeddings, chat)            SSE events)
```

**Agent pipeline:** Planner → Research (Tavily + pgvector) → Analysis → Critic (loops ≤3×) → Synthesizer

**Research depths:**
- `quick` — Planner → Research → Synthesizer (fast, no critic loop)
- `standard` / `deep` — full 5-agent pipeline with critic revision loop

## Quick Start (Local)

### Prerequisites
- Docker Desktop, Docker Compose, Make, OpenSSL, Python 3.11+

### First-time setup
```bash
make dev-setup   # creates .env, generates RSA keypair
make up          # starts all 5 services
make health      # verify everything is running
```

Open:
- Frontend: http://localhost:3000
- GraphQL: http://localhost:8000/graphql
- AI health: http://localhost:8080/health

### Daily commands
```bash
make up          # start
make down        # stop
make logs        # all logs
make logs-api    # Spring Boot logs
make logs-ai     # FastAPI logs
make restart     # restart all
make clean       # full reset (removes volumes)
make status      # container status
```

### Tests
```bash
make dev-install          # install test deps (one-time)
make test-unit            # unit tests
make test-integration     # integration tests
make test-e2e             # Playwright browser tests
make test                 # all tests
```

## Environment Variables

Copy `.env.example` to `.env` and fill in:

| Variable | Required | Description |
|---|---|---|
| `POSTGRES_PASSWORD` | Yes | Database password |
| `JWT_SECRET_KEY` | Yes | RSA private key (auto-generated by `make dev-setup`) |
| `JWT_PUBLIC_KEY` | Yes | RSA public key (auto-generated by `make dev-setup`) |
| `WEBHOOK_SECRET` | Prod | HMAC secret for AI→API callbacks |
| `INTERNAL_API_KEY` | Prod | Service-to-service auth key |
| `CORS_ALLOWED_ORIGINS` | Prod | Comma-separated allowed origins |
| `LLM_PROVIDER` | No | `mock` (default), `openai`, or `bedrock` |
| `OPENAI_API_KEY` | OpenAI | Required if `LLM_PROVIDER=openai` |
| `AWS_ACCESS_KEY_ID` | Bedrock | Required if `LLM_PROVIDER=bedrock` |
| `AWS_SECRET_ACCESS_KEY` | Bedrock | Required if `LLM_PROVIDER=bedrock` |
| `TAVILY_API_KEY` | No | Web search (falls back to mock if unset) |

Default `LLM_PROVIDER=mock` — no API keys needed to run locally.

## Deployment

### Option A: Docker Compose on a VM (simplest)

```bash
# On any Linux VM with Docker + Make installed:
make dev-setup
make up
make health
```

Open ports 3000, 8000, 8080 in your firewall.

### Option B: Kubernetes + Helm (production)

```bash
# Build and push images first, then:
cd helm
helm dependency build
helm upgrade --install meridian . -n meridian --create-namespace \
  --set externalSecrets.enabled=true \
  --set externalSecrets.secretPath="meridian/production/app-secrets"
```

Requires External Secrets Operator installed in the cluster.

### Option C: AWS (Terraform + Helm)

```bash
# Provision infrastructure
make aws-apply TF_ENV=prod

# Deploy app
helm upgrade --install meridian ./helm -n meridian --create-namespace
```

**Destroy all AWS resources (irreversible):**
```bash
make aws-destroy TF_ENV=prod   # prompts for confirmation
make aws-destroy TF_ENV=staging
make aws-destroy TF_ENV=dev
```

## API Reference

### GraphQL (Spring Boot — port 8000)
- Endpoint: `POST /graphql`
- Playground: `GET /graphiql` (dev only — set `GRAPHIQL_ENABLED=true`)

Key operations:
```graphql
mutation { register(email, password, name) { accessToken refreshToken } }
mutation { login(email, password) { accessToken refreshToken } }
mutation { createProject(input: { name, description }) { id } }
mutation { createResearchJob(input: { projectId, query, llmProvider, researchDepth }) { id } }
mutation { cancelResearchJob(id) }
query   { reports(projectId) { id title criticScore wordCount } }
query   { report(id) { content citationCount } }
mutation { sendChatMessage(input: { reportId, content }) { role content } }
mutation { deleteDocument(id) }
mutation { publishReport(id) }
mutation { exportReport(id, format: "markdown") }
```

### REST (Spring Boot — port 8000)
- `POST /api/documents/upload` — multipart file upload (PDF/TXT, max 10MB)
- `GET /actuator/health` — service health

### AI Service (FastAPI — port 8080)
- `GET /health` — checks DB + Redis connectivity
- `GET /metrics` — Prometheus metrics
- `GET /ai/stream/{jobId}?token=<jwt>` — SSE live agent updates
- Internal (requires `X-Service-Key`):
  - `POST /api/v1/jobs/start`
  - `POST /api/v1/documents/process`
  - `POST /api/v1/chat/{reportId}`

## Troubleshooting

**Services not healthy after `make up`** — wait 30–90s, then `make health`

**`make dev-setup` fails** — run `make dev-check` to see missing prerequisites

**API or AI keeps restarting** — check `make logs-api` or `make logs-ai`

**Reset everything:**
```bash
make clean   # stops containers, removes volumes, cleans build artifacts
make up      # fresh start
```
